# Segmented

Pick one option from a short set: the site, the media type, a date preset. The chosen option is filled with `ink`; the rest are `ink-2` text.

- Keep labels to one or two words. Use `tag` for a quiet qualifier ("beta").
- Arrow keys move the choice; Tab enters and leaves the group.
- It wraps onto a second line when space runs out, on phones as well, so no option is ever cut off. One height at every size; 44px touch height on phones.
- Provide: `label` (accessible name), `options`, `value`/`onChange` or `defaultValue`, optional `size`.
