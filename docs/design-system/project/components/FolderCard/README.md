# FolderCard

A sub-folder of the current path: Image, Video, a year. A bordered link with a folder glyph and the name in mono. It is never a filled tile, so thumbnails stay the loudest thing on the page.

- 48px tall. `line-strong` border, `ink-2` on hover.
- Sub-folders come first, then the files.
- Provide: `name`, `href`.
