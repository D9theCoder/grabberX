# Disclosure

Folds a section away, used for Advanced. Closed by default; the `meta` text tells you how many values differ from the defaults, so nothing is hidden by surprise.

- Title in sentence case, `meta` like "2 changed".
- Built on native `details`/`summary`: keyboard and screen readers work without extra code.
- Provide: `title`, `children`, optional `meta`, `defaultOpen`.
